# 신동고 방송부 스튜디오

교내 방송 · 진로 신문 · 영상 · 행사 중계를 **기획부터 송출까지** 함께 만드는 방송부 사이트입니다.
휴대폰에서 바로 쓰는 한 장짜리 웹사이트이고, 방송국처럼 생겼습니다.

**바로 쓰기 → https://junrepos.github.io/bangsong/**

## 무엇이 중심인가요 — 작품

방송부가 만드는 것 하나하나가 **작품**입니다. 작품은 네 종류이고, 종류마다 제작 단계가 다릅니다.

| 종류 | 제작 단계 | 자주 쓰는 역할 |
| --- | --- | --- |
| 🎙 교내 방송 | 기획 → 대본 → 리허설 → 송출 → 다시듣기 | PD · 아나운서 · 작가 · 엔지니어 · 선곡 |
| 📰 신문 · 칼럼 | 기획 → 취재·원고 → 데스킹 → 편집 → 발행 | 편집장 · 기자 · 데스크 · 교정 · 디자인 · 사진 |
| 🎬 영상 | 기획 → 콘티 → 촬영 → 편집 → 공개 | PD · 작가 · 촬영 · 편집 · 출연 |
| 🎤 행사 중계 | 준비 → 큐시트 → 리허설 → 중계 → 정리 | 총괄 · 사회 · 음향 · 카메라 · 무대 |

작품 한 장에 **방송일·시각, 크레딧(누가 무엇을 맡았나), 기획 메모, 대본·큐시트 링크, 파일, 부원이 올린 원고, 피드백**이 모두 모입니다.
마지막 단계에 닿으면 **아카이브**로 넘어갑니다.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| **ON AIR** | **다음 동아리 시간**(D-day·회차·남은 횟수), 오늘 나가는 것, **내 큐**(내가 맡은 작품·내 역할·원고 올리기), 검토할 기획안(선생님), 3주치 **편성표** |
| **제작** | 진행 중인 작품 보드. 종류별로 걸러 보고, 단계 막대로 어디까지 왔는지 한눈에 |
| **일정** | 동아리 회차표 + 달력. 동아리 시간·작품 방송일·선생님 일정·시험 같은 학교 일정이 한 달력에. 휴대폰 캘린더로 보내기(.ics, 구글 캘린더) |
| **아카이브** | 내보낸 방송 · 발행한 신문 · 공개한 영상을 달별로 |
| **스튜디오** | 부원: 내 크레딧 목록 · 선생님: 방송국 이름, 참여 코드, 부원, **크레딧 표 내려받기** |

맨 위의 **ON AIR** 불은 그날 방송이나 중계가 있으면 빨갛게 켜집니다.

**바로 가기 → https://junrepos.github.io/bangsong/paper.html**
(신문 · 칼럼 작품 화면의 노란 **신문 편집국 열기** 버튼으로도 들어갑니다)

| 탭 | 하는 일 |
| --- | --- |
| **칼럼 보드** | 패들렛처럼 부원 칼럼이 사진과 함께 벽에 붙습니다. 눌러서 크게 읽고 댓글을 답니다. 선생님 화면에는 **아직 안 올린 부원**이 뜹니다 |
| **신문 보기** | 올라온 칼럼으로 신문 지면을 자동으로 짭니다. 1면(제호·톱기사·이번 호 학과), 학과별 기사, 마지막 면(만든 사람들·편집국에서) |
| **디자인 편집** (선생님) | 제호·호수·발행일, 테마 3가지(신문 빨강·블루프린트·따뜻한 크림), A4/A3, 1면 톱 고르기, 순서, 반 면/한 면, 사진 안 자르기, 지면용 본문 고치기, 빼기 |

- 칼럼 한 편: 지망 학과 · 제목 · 한 줄 인용 · 본문 · 사진 6장까지(설명 포함, 캡처해서 붙여 넣기 가능) · 배우는 것 · 졸업 후 진로
- 학과 이름으로 계열 색이 정해집니다: 보건·의료 빨강, 공학·IT 파랑, 자연과학 초록, 인문·사회 보라, 예술·미디어 주황
- **글과 사진은 하나도 빠지지 않습니다.** 넘치면 글자를 조금 줄이고 → 반 면을 한 면으로 키우고 → 그래도 넘치면 "▶ ○면에 계속"으로 다음 면에 이어 싣습니다
- 선생님은 **지면에서 글 고치기**로 제목·인용구·사진 설명을 지면 위에서 바로 고칩니다. 학생 원문은 그대로 남고 지면용 글만 바뀝니다
- **PDF로 받기** → 인쇄 창에서 대상을 **PDF로 저장**, 여백 **없음**, **배경 그래픽** 켜기
- 교실 화면에 **학생에게 링크 띄우기**(QR 코드)를 띄우면 휴대폰으로 바로 들어옵니다

저장은 방송부 사이트와 같은 곳을 씁니다(신문 한 호 = 작품, 칼럼 = 원고, 댓글 = 피드백). 규칙을 새로 올릴 필요가 없습니다.

## 점심방송 담당

**일정** 탭 맨 위에 월~금 점심방송 담당표가 있습니다(방송 콘솔 채널처럼 다섯 칸).

- 오늘 칸에만 **ON AIR** 불이 켜지고, 내 이름은 하얗게 보입니다
- ON AIR 첫 화면에도 **오늘 마이크**(오늘 담당)가 뜹니다
- 선생님은 **고치기**에서 요일마다 이름을 쉼표로 적습니다. `아나운서 김하늘` 처럼 역할을 붙이면 이름 위에 작게 나옵니다
- 주말에는 다음 주 담당표가 보입니다

## 동아리 시간 · 일정

**2026학년도 창의적 체험활동 운영계획(2학기 변경)** 에서 옮겼습니다. 동아리는 모두 **수요일 5·6교시(13:50–15:40)** 입니다.

| 학기 | 날짜 |
| --- | --- |
| 1학기 | 3/25(조직) · 4/1 · 5/20 · 6/10 |
| 2학기 | 9/16 · **10/28** · 11/11 · 12/23, 12/24(목) 축제·동아리발표회 |

- 선생님은 캘린더에서 **일정 추가**(리허설·장비 점검·회의 등)와 **이 날 작품 만들기**를 할 수 있습니다
- **캘린더 파일 받기(.ics)**: 앞으로의 동아리 시간·일정·작품 방송일이 한 번에 휴대폰 캘린더로 들어갑니다(아이폰은 열면 바로)
- 회차표의 **구글** 링크: 구글 캘린더에 한 번씩 넣기(갤럭시)
- 학년이 바뀌면 `index.html` 의 `CLUB_DAYS`(동아리 날짜)와 `SCHOOL_DAYS`(시험 등)만 고치면 됩니다

## 누가 무엇을 하나요

- **선생님** — 반 사이트와 같은 계정. 작품 만들기, 크레딧 정하기, 기획안 채택, 단계 넘기기, 모든 글 관리
- **부원** — **학번 + 비밀번호**로 로그인합니다. 처음 한 번만 ‘처음이에요’에서 학번 · 이름 · 참여 코드 · 비밀번호로 가입하고, 그다음부터는 휴대폰 · 컴퓨터 어디서든 학번과 비밀번호로 들어옵니다.
  - 가입하면 선생님 **스튜디오 → 부원** 목록에 학번 · 이름이 바로 뜹니다(선생님 화면이 열려 있으면 알림도 뜸)
  - 비밀번호를 잊으면: 부원 목록에서 **내보내기** → Firebase 콘솔 → Authentication 에서 `bc학번@example.com` 계정 삭제 → 다시 가입
  - **기획안 올리기**: 하고 싶은 방송·기사·영상을 제안 → 선생님이 **채택**하면 제작 시작
  - **원고 올리기**: 맡은 작품에 원고·대본·큐시트·콘티·파일을 올림
  - **피드백**: 작품마다 데스킹·리허설 메모를 남김
  - **단계 넘기기**: 크레딧에 든 부원은 단계를 직접 넘길 수 있음
- **그냥 들어온 사람** — 편성표와 아카이브만 볼 수 있습니다

기기를 바꿔 들어와도(휴대폰 → 컴퓨터실) 같은 이름이면 내 큐와 크레딧이 그대로 보입니다.

## 동아리 세특 (선생님)

아래 **세특** 탭(선생님에게만 보임)에서 부원마다 정리합니다.

- **활동 근거**: 사이트에 남은 진로 칼럼(학과 · 제목 · 크기 · 글자 수 · 사진 · 직접 고른 디자인), 크레딧(작품 · 역할), 원고, 피드백, 기획안을 자동으로 모아 보여 줍니다
- **활동**: 선생님이 활동(이름 · 날짜 · 설명)을 더하면 부원 모두에게 그 활동의 메모 칸이 생깁니다. 처음에는 ‘진로 신문 ‘나의 학과를 소개해!’ 제작’이 들어 있습니다
- **활동별 메모**: 학생마다 활동마다 선생님이 직접 씁니다. 진로 신문은 **칼럼으로 메모 채우기**로 비어 있는 칸을 칼럼 내용(200자 안팎, 사실만)으로 한 번에 채울 수 있습니다
- **세특**: ‘활동 메모로 초안 만들기’를 누르면 활동 메모가 날짜 순으로 이어지고, 다듬어 씁니다 — 쓰는 대로 저장됩니다
- 초안 칸 아래에 **500자 / 1,500바이트** 카운터와 **기재요령 점검**(학교명 · 상호명 · 대학명 · 대회 수상 · 논문 · 부모 직업 등)이 뜹니다
- **세특 표 내려받기**: 학번 · 이름 · 활동별 메모 · 세특 · 글자 수 · 바이트를 엑셀로

메모와 초안은 선생님만 읽고 쓰는 곳(`bcJoin`, 참여 코드와 같은 곳)에 저장되어 규칙을 새로 게시하지 않아도 됩니다.
2026학년도 기재요령: 동아리활동 특기사항 500자, AI로 생성한 내용을 그대로 입력하는 행위 금지(윤문 보조로 쓴 경우 최종 입력 전 확인).

## 영상 — 선생님 구글 드라이브로 올리고 사이트에서 재생

- 링크 칸에 **구글 드라이브 파일 · 유튜브 링크**를 붙이면 사이트 안에서 바로 재생됩니다(드라이브 폴더 링크는 파일 목록).
- **영상을 선생님 드라이브로 바로 받기**: 선생님 구글 계정에서 [`drive-upload.gs`](drive-upload.gs)를 Apps Script 웹 앱으로 한 번 배포하고,
  그 주소(`…/exec`)를 **스튜디오 → 방송국 정보 → 영상 받을 구글 드라이브** 칸에 넣습니다. 만드는 법은 파일 맨 위에 적혀 있습니다.
  - 그 뒤로 부원이 **파일 · 사진 → 고르기**에서 영상을 고르면 크기 상관없이(5GB 까지) 선생님 드라이브 `방송부 영상 / 작품 제목` 폴더에
    `학번 이름_파일이름` 으로 올라가고, 다 올라가면 보기 링크가 링크 칸에 저절로 들어갑니다.
  - 올리는 창구는 사이트에 로그인한 **가입 부원과 선생님만** 쓸 수 있습니다(로그인 토큰과 `bcMembers` 문서로 확인).
  - 올라온 영상은 ‘링크가 있는 모든 사용자 보기’로 공유됩니다. 학교(워크스페이스) 계정은 관리자가 이 공유를 막아 둘 수 있어, 개인 구글 계정을 권합니다.
  - 드라이브 무료 용량(15GB)을 Gmail 과 같이 씁니다.

## 생기부

**스튜디오 → 크레딧 표 내려받기**를 누르면 `이름 · 작품 · 종류 · 역할 · 날짜 · 단계 · 올린 원고 수`가 엑셀로 열립니다.
동아리활동 특기사항을 쓸 때 "누가 어떤 작품에서 무엇을 맡았는지"를 바로 찾을 수 있습니다.

## 처음 한 번 해야 하는 설정

반 사이트(2-6 알리미)와 **같은 Firebase 프로젝트**를 씁니다. 저장 공간은 `bc…` 로 시작하는 곳만 따로 씁니다.

1. **Firestore 규칙** — [`schoollife/firestore.rules`](https://github.com/JunRepos/schoollife/blob/main/firestore.rules) **전체**를
   Firebase 콘솔 → Firestore → 규칙에 붙여 넣고 **게시**. (`TEACHER_EMAIL` 자리에 선생님 이메일)
   같은 프로젝트는 규칙 파일이 하나뿐이라, 반 사이트 규칙과 방송부 규칙이 한 파일에 들어 있습니다.
2. **Storage 규칙** — [`schoollife/storage.rules`](https://github.com/JunRepos/schoollife/blob/main/storage.rules) 전체를 Storage → 규칙에 게시.
3. **이메일/비밀번호 로그인** — Authentication → 로그인 방법에서 켜져 있어야 합니다(선생님 계정과 같은 방식).
4. 사이트에서 **선생님 로그인 → 스튜디오**: 방송국 이름 적고 **코드 만들기** → 부원에게 알려 주기.

규칙을 안 올리면 저장할 때 "규칙에 막혔습니다" 라는 빨간 글씨가 뜹니다.

## 저장되는 곳 (Firestore)

| 곳 | 무엇이 | 누가 봅니까 |
| --- | --- | --- |
| `bcInfo/main` | 방송국 이름 · 한 줄 소개 | 누구나 |
| `bcJoin/code` | 참여 코드 | 선생님만 |
| `bcMembers/{계정}` | 가입한 부원: 학번 · 이름 · 가입한 때 | 선생님과 부원 |
| `bcProds/{id}` | 작품: 종류·제목·날짜·단계·크레딧·링크·파일 | 누구나 (편성표) |
| `bcItems/{id}` | 부원이 올린 원고·대본·파일 | 선생님과 부원 |
| `bcComments/{id}` | 피드백 | 선생님과 부원 |
| `bcDuty/week` | 점심방송 담당(월~금) | 누구나 |
| `bcEvents/{id}` | 선생님이 올린 일정(리허설·회의 등) | 누구나 (캘린더) |

파일과 사진은 Storage `bc/` 아래에 들어갑니다(한 파일 30MB, 사진은 긴 쪽 2000px로 줄여서).

## 고치고 싶을 때

`index.html` 하나에 전부 들어 있습니다.

- 작품 종류·단계·역할: 맨 위 `KINDS`
- 원고 꼬리표(원고·대본·큐시트…): `ITEM_LABELS`
- 색: `:root` 의 `--k-air`, `--k-paper`, `--k-video`, `--k-event`, `--onair`
- `FIREBASE_CONFIG` 의 `apiKey` 를 비우면 서버 없이 이 기기에만 저장하는 **데모**로 돌아갑니다
